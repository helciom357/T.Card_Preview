# T.Card — Protótipo navegável

Protótipo do novo visual do cartão digital do vendedor e da página da loja do T.Card, produto da THOTH.

É só uma demonstração do front: os dados são de teste e os links externos (WhatsApp, ligação, Waze, Google Maps) mostram um aviso em vez de abrir o app. O código do sistema T.Card não fica neste repositório.

## Telas

- `#nfc/marcus` — chegada pela tag NFC (envelope que revela o cartão físico)
- `#c/marcus`, `#c/cidney`, `#c/juliana`, `#c/rafael`, `#c/patricia` — cartão do vendedor
- `#loja/demo` — página da loja com o carrossel de consultores

## Arquivos

- `index.html` — o protótipo inteiro (HTML, CSS e JavaScript, sem dependências além das fontes do Google Fonts)
- `assets/` — logo da THOTH, logo de teste da loja, ilustrações dos vendedores e figurinhas
